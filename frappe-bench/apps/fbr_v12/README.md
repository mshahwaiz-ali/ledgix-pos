# Retired Digital Invoicing V1.2 app identity

This package is a non-executable tombstone for existing historical sites. New installation fails explicitly. There are no invoice hooks, HTTP transport, credentials, payload execution, setup synchronization, or standard JSON assets. Retained controller stubs resolve historical metadata and reject writes; retained functions reject before any I/O.

Do not install or build this as a current integration. Do not automatically uninstall it from an existing site. Any site still listing it needs a separately controlled metadata/data-preservation and uninstall operation. Source implementation remains in Git history; historical documentation remains under docs/fbr/fbr_v12.
