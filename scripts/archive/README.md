# Archived scripts

These scripts are intentionally retained for migration history, test evidence,
forensics, and rollback/reference work.

They are not current operator entrypoints.

- `erpnext_migration/` contains completed ERPNext-native migration phase gates.
- `fbr_v12/` contains retired Digital Invoicing V1.2 / pre-V1 redesign helpers.
- `release_migration/` contains completed historical R1-R5 release-phase gates.

Current operational scripts live in `scripts/core`, `scripts/validation`,
`scripts/local`, and `scripts/release`.
